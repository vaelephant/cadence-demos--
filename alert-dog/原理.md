# 血糖警报犬：原理与在训练什么

这只「狗」在学的不是预测血糖曲线，而是**在什么情况下该提醒、什么时候该闭嘴**。

本文对应 `README.md` 里的设计与测量；数字以 `evidence/` 为准。**这是模拟器里的研究演示，不是医疗器械，不能用于真实诊疗。**

## 它是什么

一个持续运行的 Cadence 大脑（`Brain.compose`）：

- **输入 36 维**：当前血糖、15 分钟趋势、时刻、身上胰岛素/碳水、距上次运动多久、是否睡着、是否刚补过糖
- **中间**：联想区 + 前额区
- **输出 2 个运动神经元**：`不出声` / `提醒`

每 5 分钟看一眼世界，两个输出里哪个更强，就做哪个动作。提醒后患者会查血糖；真的低了或趋势要低，就吃 15g 糖。

平静时只做一次「稳定下来」的计算，不改权重；结果出乎意料时（或刚到新家的第一天）才警觉：采样、学习、写记忆。

## 训练分两段

### 1. 犬舍（真正的「预训练」）

新生大脑跟**训练师**学 60 天：10 个虚拟患者 × 各 6 天。训练师就是血糖仪趋势规则（低于 75，或按趋势 20 分钟内会到 70 以下就报警）。

学法很像真警报犬：

- 训练师每次提醒 → 给狗上一课
- 训练师安静时 → 大约 5% 的时刻也上一课（别只会乱叫）
- 用 `stimulus` + `learner.step` 教它「这种局面该提醒 / 该安静」

出笼后「长大」（`ADULT`）：学习步长变小、采样更尖，到家后只能微调，不能把犬舍学的全冲掉。大脑存进 `brains/kennel-*.npz`。

**犬舍在训练什么：** 一般性的「低血糖前兆 → 要不要叫」的经验，不是某个特定患者的档案。正式测评用的患者 `adult#001` 从未进过犬舍。

相关代码：`alertdog/kennel.py`、`alertdog/companions.py` 里的 `watch`。

### 2. 到家之后（继续活、偶尔学）

页面上跑的就是这段。入口是 `Brain.live`：

- **平静**：算一次就定下来，**不改权重**
- **警觉**（结果出乎意料，或到家第一天的「青年期」）：采样、学习、写情景记忆

「出乎意料」来自上一刻决策之后真实发生的事。奖励全是代价（越低越好避）：

- 5 分钟里血糖 &lt;70 → 罚
- &lt;54 → 再罚
- 每次提醒也罚一点（白天 0.2，夜里 0.5）——防止乱叫

没人告诉它「现在该提醒」；它也看不到未来，只拿**决策之后患者实际过得怎样**当反馈。

**到家在训练什么：** 在这位新患者身上，把犬舍带来的策略再对齐一点——该叫时叫、少误报。实测平均比「冻住不再学」略好，但不是每段生活都更好；也**没有超过**训练师那条规则。

相关代码：`alertdog/companions.py` 里的 `Dog.decide`、`alertdog/life.py`、`server.py`。

## 一句话对照

| | 在学什么 | 怎么学 |
|---|---|---|
| 犬舍 | 跟着趋势规则，学会「何时提醒」 | 看训练师示范，主动上课 |
| 到家 | 同一套决策，用真实后果微调 | 只有意外（或第一天）才改突触 |
| **不是** | 预测 30 分钟后血糖、开药、调胰岛素剂量 | — |

## 它不是什么

- **不是 Transformer / MLP 分类器**：不是把一段窗口压成一次观测、每步都更新标签的那类网络。
- **不是世界模型（按严格说法）**：它不预测下一步血糖，只做「提醒 / 不提醒」的决策；页面上的 surprise 是行为后果与预期的差，不是血糖预报误差。
- **不是医疗产品**：只在 simglucose 虚拟患者上测过。

## 和页面上对照组的关系

三个家庭同一位患者、同一套随机日常，只换陪伴者：

- **Cadence 警报犬**：犬舍训练 + 到家按觉醒学习
- **趋势规则**：狗的训练师，也是对照上限之一
- **没有提醒**：患者只靠自己察觉低血糖
